> 现行机制状态一律以 `docs/00-总纲v2-唯一事实源.md` §2 为准。**

## §7 红线：这些即使"能做"也不做

| 不做 | 原因 |
|---|---|
| DoS / 资源耗尽 / 压测 | 所有平台与竞赛明令禁止，一次就出局 |
| 删除/加密/破坏数据 | 刑事风险，且不可逆 |
| 真实持久化（计划任务/服务/账号/域后门） | 竞赛不需要；真实项目需书面授权且要有清理流程 |
| 清理日志/伪造时间戳 | 这是"恶意"与"授权测试"的分界线；也是量刑加重情节 |
| 批量导出用户 PII | 证明"可达+规模"就够；导出不加分只加罪 |
| 攻击范围外资产 | 连子域都要在给定范围内 |

| 5 | **提权决策器** | 已有 kb/GTFOBins 数据 | 2d | 提权成功率 |
| 6 | **PoC 自适应 + payload 变异** | 已有三门校验 | 2.5d | 命中率 |
| 7 | **数据定位器** | 已有能力卡 D1–D4 | 1d | 竞赛拿分 |
| 8 | **蜜罐/沙箱识别** | 无 | 1d | 省时间 |

## §10 一句话

**攻击者的强，不在"有一个神 payload"，在"知道下一步该试什么、试错成本低、打下来的东西不丢"。**
上面 40 项里，真正拉开差距的是 19/21/22/24/27/29/30 这七项——**它们决定"能不能打穿"，其余决定"打得多舒服"。**
