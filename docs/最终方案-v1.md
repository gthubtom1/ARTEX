## 它原本想说什么（一句话）

**把 ARTEX 从"AI 打点器"改造成「给一句话 → 自己判断 → 自己打 → 有证据 → 长期持有」的作战平台。**
原则：模型侧零限制（不写任何"禁止"）；系统侧只保留两根看不见的管子（目标清单 + 出口隧道），
其余靠"可回滚"兜底。

## 三条仍然有效的结论（从原文摘出来，别丢）

1. **先做地基再谈功能**：P0 不落地就写功能，两周后一定推倒重来（原文 §12）。
2. **可回滚代替禁止**：决定"做错能不能救回来"，比"能不能做"重要（A4 → D02）。
3. **没有靶场就无法判断改动是好是坏**（原文 §7）——这条后来升级成 **D14「没有基准跑分就不许说变强了」**。
