# 28 · 界面规格书（组件 / 样式 / 位置）— 让人 3 秒找得到

> 要求（用户）："你要设计得完整一点，不要按 AI 的思路想——AI 觉得'在那个位置就行了'，
> 但真人要好分辨、好定位。组件的设计、风格的设计都是有要求的。"
>
> 本文是**规格**，不是示意图：每个组件给尺寸、位置、颜色语义、交互反馈、空态/失败态。
> 落地顺序见 §八（和 docs/27 的 P0/P1 合并执行）。

---

## 一、六条原则（先立规矩，再谈外观）

| # | 原则 | 反面（我们现在犯过的） |
|---|---|---|
| 1 | **一屏一问**：主视线只回答一个问题，其它都折叠 | 8 张管理卡堆在战况卡下面 |
| 2 | **标签靠左、内容靠右、纵向对齐**（`label 64px + content`），扫读时眼睛只走一列 | 行内 `我的目标是 [下拉] [状态] [就做这个]` 全部挤成一串 |
| 3 | **颜色只表语义**，不表装饰（见 §二）；同一含义全局同色 | 绿=能做/绿=成功/绿=复制按钮，三种绿混用 |
| 4 | **危险/花钱/不可逆**必须有**形状差异**（图标 + 边框 + 位置），不能只靠颜色 | 全部圆角小方块，色弱/色差就分不出 |
| 5 | **每条结论必须带数字或证据号**，禁止只有形容词 | "还没探够" |
| 6 | **任何元素点击都要有反馈**：<=100ms 视觉变化 / toast / 载入态 | 点"重算"没反应（已修） |

## 二、语义色 token（全局统一，禁止自创）

| 语义 | 色 | 用在哪 | 形状/图标 |
|---|---|---|---|
| **已成立 / 能做到** | emerald-600 | 目标状态"现在就能做到"、三段式 `已成立`、能做的高亮 | 实心标 + ✓ |
| **差一步 / 注意** | amber-500 | `差一步`、卡在哪、无进展 | 描边标 + ▲ |
| **做不到 / 无关** | slate-500 | `换不到`、还做不到（灰但可读，不能灰到看不见） | 描边标 + ○ |
| **危险 / 阻塞** | rose-500 | 目标"现在做不到"、破坏性动作、被拒 | 粗左边框 3px + ⛔ |
| **信息 / 中性** | sky-600 | 我在哪、继承、下一步提示 | 左侧细条 2px |
| **AI 产出** | violet-500 | `✦ 分析`、`AI` 角标、我的目标块 | 紫角标 + ✦ |
| **可点击（主）** | 前景色描边 | `[就做这个]`、`[照这句说]` | 按钮，hover 有底色 |

规则：**同一屏内语义色不超过 4 种**；"绿/amber/灰"三种状态标**永远同一尺寸**（高 18px，字号 10px，圆角 3px），这样眼睛能对齐比较。

## 三、字号 / 间距 / 圆角（统一，别再各处 `text-[10.5px]` 乱飞）

| 用途 | 规格 |
|---|---|
| 卡片标题 | 15px / 600 |
| 区块小标题（"我在哪""我的目标是"） | 10px / 600 / `text-muted-foreground` / 固定宽度 **64px**，右对齐或左对齐二者择一（本规格：**左对齐固定宽**） |
| 正文 | 12px / 400 / 行高 1.55 |
| 辅助（证据号、成本） | 10.5px / `muted-foreground` |
| 状态标 | 10px / 700 / 高 18 / 圆角 3 |
| 卡片内边距 | 12px（`px-3 py-2.5`） |
| 区块间距 | 10px（`gap-2.5`） |
| 圆角 | 卡片 10px、区块 8px、状态标 3px、按钮 6px |

## 四、战况卡线框（`BattleCard`，一屏一问）

```
┌ 战况   [值得打]        [战果+5]        [✦ 分析] [刷新] ┐   抬 44px
├──────────────────────────────────────────────────────┤
│ 我在哪    E2 应用控制  ●●○○○○  已确认 6 个洞            │  label 64
│ 我有什么  [后台会话] [数据样本] …还有 3                  │
│ ────────────────────────────────────────────────────  │ 分隔 1px
│ 我的目标  [拿后台 ▾]      [现在就能做到 ✓]               │  ← 主视线焦点
│           往哪儿深究（按省时省钱）                       │
│           ① 试一次出厂默认口令（只 3 组）  [成本 3 次][照这句说]│
│           ② 拿 #341 去试 /api/account/list  [成本 1 次][照这句说]│
│           可以对它说： [继续] [换路线] [收工]             │  三色按钮
│ ────────────────────────────────────────────────────  │
│ ⛔ 卡在哪  target_blocked ×12 —— WAF 拦，换手法或降频     │  rose 左边框
│ ────────────────────────────────────────────────────  │
│ 现在能做到 ①…②…③…  还有 4 件                            │
│ 差一步  3 个洞 —— 缺：管理员会话                          │
│ 换不到  2 个洞                                           │
│ ▸ 6 个洞 · 每个能换到什么  ▸ 7 件能做到的事  ▸ 链  ▸ 越界 ▸ 依据 │
└──────────────────────────────────────────────────────┘
```

**具体的三大改动（现在缺的）**
1. **加 label 列**：所有行统一 `grid-cols-[64px_1fr]`，纵向对齐；现在标签是行内文本，扫读找不到。
2. **目标块独立成"焦点区"**：violet 左边框 3px + 浅底，状态标在标题行右侧；Top3 每条**两行**（第一行做事，第二行成本/成功长相/不成）。
3. **卡在哪升格为告警条**：rose 左边框 3px + ⛔ 图标，位置在目标块之后、能力之前（先看阻塞再看能力）。

## 五、组件规格（逐个）

### 5.1 `StatusChip`（状态标，全局唯一）
- 尺寸/字号固定（§三）；三种 tone：`ok | warn | muted | danger`；
- 必须带 `title`（悬停解释，不许只有颜色）；
- 禁用"半透明文字"表达状态（可读性）。

### 5.2 `LabelRow`（带左标签的行）
- `grid-cols-[64px_1fr] gap-2 items-start`；标签 10px/600/muted；
- 一行最多 2 行高；超出即折叠（"还有 N"）。

### 5.3 `GoalBlock`（我的目标）
- 标题行：`我的目标` 标签 + `<select>`（宽 240px，native，键盘可用）+ 状态标 + `[就做这个]`；
- 状态为 `unlikely`：状态标换成 rose 描边 + 文案"这站看不出有这类东西"，并**隐藏**[就做这个]（避免误点花钱）；
- 第二行：一句 `why`（10.5px muted）+ 风险（同色系）；不换行超过 2 行。

### 5.4 `MoveList`（往哪儿深究）
- 每条：序号（14px 圆形数字）+ 主句（12px）+ 右侧 `[成本 1–3 次]` 小 chip + `[照这句说]` 按钮；
- 第二行（10.5px muted）：`成功长相：…`；`不成：…` 用 amber；
- 最多 3 条；每条点击整行 = 复制（和按钮等价），避免"点哪里算复制"。

### 5.5 `SayBar`（可以对它说）
- 三个按钮等宽（各 88px）：`继续`（绿描边）/`换路线`（sky 描边）/`收工`（rose 描边）；
- 点击=复制到剪贴板 + toast"已复制，粘到下方输入框发送"；**绝不自动发送**。

### 5.6 `BlockerBar`（卡在哪）
- rose 左边框 3px + ⛔；一行内 `类别 ×次数 —— 建议`；最多 2 类，其余"+N"。

### 5.7 `LootRow`（战果行）
- 主句 12px（白话）+ 副行 10px（归类名）；状态标在**最左**（固定 64px 列），依据号右对齐；
- 悬停整行高亮（`bg-accent/40`），点击行 → 展开详情（整行可点，不是只有小箭头）。

### 5.8 `TaskRow`（任务列表）
- 6 列固定宽度：`名称 flex | 状态 96 | 漏洞 120 | 进度 80 | 时长 72 | 操作 128`；
- 未读红点紧贴名称右侧（不换行）；不再出现被压缩的列头（"运行时"→"时长"）。

### 5.9 `FindingRow`（发现页）
- 三段式标在最左固定列；主句 12px；`证据强度` 用 3 格小方块（▮▮▯）而不是文字；
- 点击整行展开报告（现在要点"查看报告"链接）。

## 六、空态 / 载入 / 失败（必须说人话，且给下一步）

| 场景 | 文案与动作 |
|---|---|
| 无漏洞 | "还没确认任何漏洞 —— 先跑①（20 分钟判断）或③（40 分钟找洞）" + `[复制这句去说]` |
| 无权限（E0） | "现在一件都做不了 —— 前置还没满足"（不要显示 7 行灰色动作） |
| 目标不可能 | "这站看不出有这类东西（依据：…）；建议换目标：[进后台][看样本]" |
| 载入 | 骨架条（高度固定，避免跳动），>2s 加"正在读战况…" |
| 失败 | "模型这次没给出结果，先看规则版" + 重试按钮；禁止只显示英文/堆栈 |

## 七、可访问性 & 键盘

- 所有可点元素：`focus-visible` 外环 2px；Tab 顺序 = 视觉顺序；
- 颜色对比：正文 ≥ 4.5:1；灰色状态标 ≥ 3:1（"灰但可读"）；
- 命中区域 >= 28×28；行内按钮间最小间距 4px；
- 不依赖颜色传达状态：状态标必须带文字（`已成立/差一步/换不到`）。
