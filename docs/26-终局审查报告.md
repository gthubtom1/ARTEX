## 六、最终回归（2026-10-24，Kali VM 0.11.32）

脚本 `scripts/vm-final.sh`（真机、走真实 DB）。判据一次跑完：服务/迁移、战况卡自洽、
动态短语、动作工单、未读、审查官最近一次、三端一致性。

**任务 14（E4 数据访问，已拿到东西的一端）**
```
health  {"ok":true,"version":"0.11.32"}      迁移 0017_template_primary.sql
brief   E4 数据访问 / has 3 / can 1（got 1，其中 1 条 AI 版）
        doable 6 · 做不到 1（persist=没命令执行）  actions 全 idle
        new_since 0 · stall ok
phrases 5 条，has=[db,cred]，第一条「把订单表按时间倒序取前 20 条…」
actions 工单 5 条全部 done 且带证据（同一句重复发话会留历史，UI 显示最新一条）
unread  total 25，本任务 2
三端一致 can_n=1 = db_findings 1；loot_seen=298 → new_since 0；action_runs open 0 / total 5
```

**任务 17（E0 仅有信息，什么权限都没有的一端）**
```
brief   E0 仅有信息 / has 0 / can 1（one_step）
        doable 0 · 做不到 7   ← 一个后果都没点亮（正是用户最早指出的问题）
        actions 全 idle · stall ok
phrases 5 条，第一条「用这条凭据登录一次，把登录成功的页面和账号权限范围记下来」
```

**结论**：两端都自洽 —— 有战果的一端该亮的亮（6 件）、没战果的一端一件都不亮（7 件全"还做不到"），
且"等级 / 已拿到 / 能做到 / 未读 / 战果 / 报告"六处口径一致。
