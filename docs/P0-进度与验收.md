## §2 来自 schema 审计的 5 处关键修正（都已改进迁移）

| 审计发现 | 原设计 | 已改为 |
|---|---|---|
| `last_seen` 已存在（schema.sql:80） | 会 ADD 冲突 | 删除该 ADD，只加 `first_seen` 并用 `created_at` 回填 |
| 交付物表用 `CASCADE` 会**静默丢证据** | `capabilities/assumptions/evidence_timeline.task_id CASCADE` | 全部 `SET NULL`（列可空） |
| `audit_log` 不该有外键 | `task_id REFERENCES tasks` | 改为 `BIGINT NOT NULL DEFAULT 0`，无 FK（与 `notification_events.finding_id` 政策一致） |
| `tools_cache` 与 `mcp_tools_cache`/`tools` 易混 | `tools_cache` | 改名 `local_tools_cache` |
| `creds_vault` 与 `task_intelligence(kind='credential')` 语义重叠 | 未说明 | 注释写死分工：情报叙述 vs 加密秘密本体 |
| 迁移文件没被应用引用（手工 psql） | 只落文件 | 新增 runner + `schema_migrations` 账本，启动自动执行 |
| 缺业务幂等键 | 只有 `asset_key` | 补 `uq_access_refs_key` / `uq_routes_task_cidr` / `uq_capabilities_item` / `uq_creds_fingerprint` / `uq_assumptions_text` / `uq_evidence_ref` / `uq_asset_checks_key` / `uq_change_events_key` |
