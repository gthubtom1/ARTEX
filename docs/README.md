## 四个"不要做"

| 不做 | 原因 |
|---|---|
| 重写 agent 运行时（工具循环/上下文压缩） | norma SDK 已经成熟，重造只会更差（hxbai 复盘结论） |
| **自建测绘层**（子域爆破器/指纹库/端口库/target_pool） | 原项目已有资产图 + enrich + ScopeSentry 同步 + api-recon，重造无收益 |
| 从测绘引擎批量捞目标 | 目标是给定的；目标**内部**扩展（子域/站群）才算合法范围 |
| 全自动到底不给决策点 | 零基础用户无法判断真假；必须"先出菜单再执行" |
| 导出/破坏类操作 | 证明"可达 + 规模"足以得分；导出只会多一条违规证据 |
