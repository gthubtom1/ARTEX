# 渗透成功后「所有能做的事」完整清单（13 组 · 82 项）

> 用途：侦察阶段把每一项都判成「能 / 不能 / 待确认」，构成能力卡菜单。
> 三列关键：**证明级别**（到哪一级算证据）、**价值**（赏金/竞赛分）、**阶段**（recon 是否允许）。
> 证明级别：`P1` 只读证明 → `P2` 单条样本 → `P3` 可利用 → `P4` 批量/持久（侦察阶段一律禁止 P4）。

## 能力卡的统一格式（覆盖上面所有项）

```yaml
id: cap-0013
group: 数据            # 1-13 组
item: 1.1              # 上面表格的编号（便于统计覆盖面）
can: 用户库可达，12.4 万条，含手机号与收货地址
surface: /api/order/detail?id=  +  MySQL 3306
proof_level: D3        # 数据类用 D 级，其它用 P 级
evidence: "SELECT COUNT(*) FROM users → 124301；information_schema 显示 phone/address 列"
impact: 万级用户 PII 可读
bounty_value: ★★★★
risk: 读 1 条也留日志；批量导出触发风控且违规
next_if_approved: 只多取 1 条证明可关联（≤1 行，打码）
forbidden: 导出全量 / 写入 / 删除
```
